# RUST_CODES
The Rust version of VISTAS Advanced package is now available. The main.rs file contains the main algorithm that saves the Output power intensities, total outputpower and carrier density (N). 

For the context, the VISTAS Advanced package is originally in MATLAB programming language developed by Jungo et al. in 2003. The author would like to thank Jungo et al. in developing a free, open source, VCSEL simulator.
